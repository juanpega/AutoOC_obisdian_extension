# AutoOC 1.7.20 — Selección de modelos y agentes de OpenCode 2

## Elegir el modelo predeterminado

1. Abre **Ajustes → AutoOC**. En **Interactive CLI launchers**, configura **OpenCode 2 CLI executable** y usa **Check version** para comprobar que la ruta corresponde a OpenCode 2.
2. Justo debajo de **Default AI engine**, busca **Default OpenCode 2 model**. Pulsa **Refresh Models** y selecciona el modelo. Las tareas nuevas de OpenCode 2 usarán esa elección.
3. En **Default OpenCode 2 agent**, pulsa **Refresh Agents** para elegir también un agente predeterminado.

## Cambiar la selección para una tarea

Al crear o editar una tarea de OpenCode 2 puedes cargar las opciones de su **Project Path** y elegir otro modelo o agente. **Enter manually…** permite escribir el identificador. La selección se conserva al cambiar entre el modo automático y el interactivo.

Si la instalación tarda en mostrar los agentes del proyecto al arrancar, AutoOC vuelve a consultar el catálogo antes de mostrar las opciones. Si se configuró un ejecutable de otra versión, la fila indica qué ruta revisar.
